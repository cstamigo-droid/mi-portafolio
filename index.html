SpringEduManager

Java 21 · Spring Boot · MVC · Data JPA · Security · REST

Aplicación web para gestionar estudiantes, cursos y evaluaciones. Separa controlador, servicio y repositorio; distingue dos roles con permisos distintos y expone una API REST para integrarse con otros sistemas.

Al cerrarlo encontré que la API redirigía al formulario de login en vez de responder 401: un programa que la consumiera no podía distinguir un rechazo de una respuesta válida. Corregido y verificado con 35 comprobaciones sobre la aplicación corriendo.

Biblioteca Digital UNTEC

Java EE · Servlets · JSP · JDBC · DAO · MVC · Tomcat

Aplicación web de préstamos de libros construida con Java EE puro, sin framework: servlets como controladores, JSP como vistas, capa DAO sobre JDBC y sesión propia para el control de acceso. Se empaqueta como WAR y se despliega en Tomcat.

Es el proyecto donde entendí qué hace Spring por debajo. También donde aprendí a revisar el bytecode del WAR antes de entregarlo: compilado con la versión de Java equivocada, la aplicación devolvía error 500 en un servidor distinto del mío.

Radar de Datos · Guardián PYME

Java · POO · interfaces · consola

Agente de consola que revisa un equipo y diagnostica riesgos de datos antes de que se pierdan: bases sin respaldo, datos personales expuestos, credenciales en texto plano y disco lleno. Seis detectores distintos detrás de una misma interfaz.

Sólo lee metadatos —nombres, tamaños, tipos— y nunca copia ni envía el contenido. Esa restricción se decidió antes de escribir el primer detector, porque una herramienta que revisa datos ajenos tiene que poder explicar qué no hace.

SmartTask

Java · herencia · polimorfismo · JUnit 5 · Mockito

Gestor de tareas por consola con jerarquía de clases —tareas normales y urgentes que se comportan distinto tras la misma interfaz—, persistencia mediante DAO y pruebas unitarias con informe de cobertura.

02 Servicios y APIs

AEGIS

Python · FastAPI · PostgreSQL · Docker

Servicio que intercala una aprobación humana antes de que un proceso automático ejecute una acción sensible. Doce rutas documentadas y un control de duplicados para que reintentar una petición no la ejecute dos veces.

La idea salió de un problema concreto: si el cliente reintenta porque se cortó la red, el servidor no puede saber si es una acción nueva o la misma de antes. La respuesta fue que el cliente nombre cada operación.

Hermes

JavaScript · Procesamiento en el navegador

Herramienta de análisis que procesa archivos enteramente en el navegador: se arrastra un archivo, se calcula en el equipo del usuario y no se envía un solo byte al servidor.

Decidir que nada saliera del navegador obligó a reescribir el motor de cálculo, pero eliminó de raíz la pregunta más incómoda que puede hacer un usuario: qué hacen ustedes con mis datos.

04 Herramientas publicadas

Cinco paquetes están en el índice público de Python: cualquiera los instala con pip install, lo que obliga a algo que un repositorio no obliga —que el empaquetado, las dependencias y la versión estén bien—.

  • argos-watchdog Detecta sistemas que están "arriba" pero dejaron de hacer su trabajo. Llena el hueco entre el proceso respondió y el proceso cumplió su propósito. Python · YAML · sólo lectura
  • rag-starter Convierte una carpeta de documentos en un servicio de preguntas y respuestas con citas: cada afirmación es rastreable al pasaje del que salió. Funciona sin clave de API y sin conexión. Python · FastAPI · ChromaDB · MCP
  • signal-scannerPyPI 0.1.0 Filtra listas de instrumentos según reglas escritas en YAML, sin tocar código. Los indicadores se calculan sobre datos cerrados, y un símbolo sin datos se reporta como tal en vez de inventarse. Python · reglas declarativas
  • market-data-mcpPyPI 1.0.0 Servidor bajo el estándar MCP que entrega datos de mercado en vivo a cualquier modelo de lenguaje. Python · MCP
  • equity-intel-mcpPyPI 0.1.0 Servidor MCP de análisis de acciones: información societaria, valuación y presentaciones ante el regulador. Python · MCP
  • crypto-intel-mcpPyPI 0.1.0 Servidor MCP equivalente para el mercado de criptomonedas, con precios y métricas de varias fuentes. Python · MCP
  • aegis-idempotencyPyPI 0.1.2 Cliente asíncrono del servicio AEGIS, para pedir aprobación humana desde código con garantía de ejecución única. Python · asyncio

05 Sistemas propios

Además de lo anterior mantengo un conjunto de sistemas en repositorios privados, casi todos en Python. No los puedo enlazar, pero son donde practico arquitectura, tareas programadas, integración entre servicios y tolerancia a fallos. Los menciono porque explican de dónde salen varias de las decisiones que sí se pueden ver arriba.

Orquestación y datos
Plataforma central que coordina alrededor de noventa tareas programadas, con registro durable de eventos, verificación de efecto por componente y panel web de estado.
Servicios de análisis

Asistentes y automatización

Plataforma de postventa
